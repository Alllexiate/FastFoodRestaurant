## Fast and Foodeus - Restaurant Management

## Project Description
A Java console-based application that simulates the basic operations of a fast-food restaurant. The system separates responsibilities among administrators, managers, employees, and customers.

 ## Features:

### Admin
- View accounts
- Add accounts
- Change account roles
- Reset passwords
- Delete accounts
- View menu database

### Manager
- View menu
- Add food item
- Set price
- Set discount
- Remove food item
- View financial report
- Restore default menu items

### Employee
- View active orders 
- Update order status
- View ready-to-serve orders
- Cancel/Delete Order
- Print receipts
  

### Customer
- View menu
- Place order
- View my orders

## Disclaimer
This project is intended for educational purposes. Do not use real passwords or personal information in demonstration data.

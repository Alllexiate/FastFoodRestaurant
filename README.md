## Fast and Foodeus - Restaurant Management

## Project Description
A Java console-based application that simulates the basic operations of a fast-food restaurant. The system separates responsibilities among administrators, managers, employees, and customers.

 ## Features:

### Admin
- View user accounts
- Add accounts
- Change account roles
- Reset passwords
- Delete accounts
- View food and order records

### Manager
- Add food items
- Change prices
- Apply discounts
- View financial reports

### Employee
- View pending orders
- Update orders to Ready to Serve
- View order details

### Customer
- View available food items
- Place orders
- View order status

## Disclaimer
This project is intended for educational purposes. Do not use real passwords or personal information in demonstration data.
